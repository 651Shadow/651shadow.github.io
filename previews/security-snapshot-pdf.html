Finding Format Walkthrough: Server-Side Request Validation

Severity: High  |  Affected area: Server-side integration proxy

Risk: An attacker can make the server reach internal metadata or private network targets when requested URLs are not validated.

Safe reproduction: Confirm whether routes reject non-HTTP schemes, local/private IP ranges, cloud metadata hosts, embedded credentials, DNS rebinding, and redirects.

Recommended remediation: Validate every outbound URL prior to fetch, resolve and inspect destination IPs, block private ranges, disable redirects, and add regression tests.

Controls Verified Working

  • Kill switches for checkout, proxy, webhooks, and email that fail closed.
  • Payment status verified directly with provider rather than trusting webhook body.
  • API keys hashed with Argon2id; upstream credentials encrypted with AES-256-GCM.
  • Constant-time signature comparisons and zero secrets committed to Git history.
